## 4. 任务书模板

```markdown
# 任务：<一句话标题>

## 目的
<为什么做，解决什么问题，对应哪个用户反馈>

## 验收标准（可测）
- [ ] ...
- [ ] ...

## 非目标
- 本次明确不做：...

## 约束与假设
- 技术/时间/兼容性/环境约束：...
- 关键假设（不成立需回头改哪一层）：...

## 方案要点
- 总体方案：...
- 模块与接口：...
- 实现步骤（L3）：1) ... 2) ... 3) ...

## 影响面与风险
- 触及文件/模块（= 写范围）：...
- 风险与缓解：...

## 验证方式
- 审计要点：...
- 短测/回归用例：...
- 真机路径：...

## 回退方案
- 失败时如何归零：...
```

**要求**：验收标准可判真假；步骤可独立分配；风险必须有缓解动作；写范围必须具体到文件/目录。
